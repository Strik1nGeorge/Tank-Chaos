# README media

The PNG screenshots were captured from the published
[TankChaos 2D v1.0.1 Windows x64 release](https://github.com/Strik1nGeorge/Tank-Chaos/releases/tag/v1.0.1).
They show the actual application, cropped to its central arena or menu area to
remove empty side margins and unrelated desktop overlays. Gameplay and UI have
not been reconstructed or retouched.

| File | Content |
|---|---|
| `gameplay.png` | The Proving Grounds, with the player tank, enemies, and arena cover |
| `combat.png` | Live combat after switching to the three-pellet shotgun |
| `main-menu.png` | The main menu and its navigation buttons |
| `garage.png` | The garage preview and body, track, and barrel palettes |
| `level-select.png` | Sequential level selection, with later levels still locked |

`tank-chaos-icon.svg` is an original vector illustration inspired by the green
player tank and the game's square-based art style. It is used as README artwork;
the released executable and Unity player settings are unchanged.
